## Migration overview

| Area                | Required action                                                                            |
| ------------------- | ------------------------------------------------------------------------------------------ |
| Modal               | Replace `Modal` and `ModalLoading` with `ModalService`, `ModalHost`, and `LoadingService`. |
| AG Grid             | Replace the preview API with generic `AGGrid<TData>` and typed Community APIs.             |
| Tabs and Menu       | Replace index- or label-based selection with stable string keys.                           |
| Tree                | Replace the old model/context contract with `Model`, `Context`, and `TreeItem`.            |
| Toast               | Replace the old imperative configuration flow with `Toast` or `ToastContainer`.            |
| Forms and date/time | Adopt typed values, validity/event models, enum parameters, and iX 5.2 defaults.           |
| Localization        | Rename public `I18N...` and `i18n...` C# parameters to `I18n...`.                          |

## Removed and replaced APIs

### Components

| Removed                 | Replacement                                                              |
| ----------------------- | ------------------------------------------------------------------------ |
| `Modal`, `ModalLoading` | `ModalService`, `ModalHost`, and `LoadingService`                        |
| `Drawer`                | Use `Pane`, `Blind`, or `Modal` according to the interaction             |
| `MapNavigationOverlay`  | No direct replacement; compose the required map controls and layout      |
| `ValidationTooltip`     | Use field validation text or `HelperText`                                |
| `SplitButtonItem`       | Place current dropdown content, such as `DropdownItem`, in `SplitButton` |

### Parameters, events, and enum members

| Removed API                                                       | Replacement or action                                      |
| ----------------------------------------------------------------- | ---------------------------------------------------------- |
| `Application.ThemeSystemAppearance`                               | `Application.ColorSchema`                                  |
| `Button.DataToggle`, `AriaLabelButton`, `Selected`, `DataTooltip` | Use current content, state, and accessibility parameters   |
| `IconButton.DataTooltip`, `A11yLabel`, `Selected`                 | Use current tooltip, state, and accessibility parameters   |
| `BreadcrumbItem.AriaLabelButton`                                  | Use the current Breadcrumb accessibility API               |
| `Checkbox.ValidationState`                                        | Removed; there is no Checkbox validation-state replacement |
| `CustomField.IsFileUpload`, `FileDisplayText`                     | Use current `CustomField` content and parameters           |
| `DropdownHeader.ChildContent`                                     | Use the current Dropdown header content model              |
| `EventListItem.Opacity`                                           | Use official EventList styling and variants                |
| `ExpandingSearchVariant`                                          | `ButtonVariant`                                            |
| `ModalHeader.Id`, `ModalContent.Id`, `ModalFooter.Id`             | Element identity is component-managed                      |
| `Select.AriaLabelChevronDownIconButton`                           | Use the current Select accessibility API                   |
| `Slider.Error`                                                    | Use label, helper, and validation parameters               |
| `SpinnerVariant.sencodary`                                        | `SpinnerVariant.secondary`                                 |
| `WorkflowSteps.Linear`                                            | Use the current workflow layout                            |

## Shared naming and typing

### Localization parameters

Public C# localization parameters now consistently use `I18n`:

| 0.5.5                            | 0.6.0                            |
| -------------------------------- | -------------------------------- |
| `CardList.I18NMoreCards`         | `CardList.I18nMoreCards`         |
| `CardList.I18NShowAll`           | `CardList.I18nShowAll`           |
| Menu `I18N...` parameters        | Menu `I18n...` parameters        |
| `MenuAvatar.I18NLogout`          | `MenuAvatar.I18nLogout`          |
| `MenuAboutNews.I18NShowMore`     | `MenuAboutNews.I18nShowMore`     |
| Date/time `I18N...` parameters   | Date/time `I18n...` parameters   |
| `Select.i18nPlaceholder`         | `Select.I18nPlaceholder`         |
| `Select.i18nPlaceholderEditable` | `Select.I18nPlaceholderEditable` |
| `Select.i18nSelectListHeader`    | `Select.I18nSelectListHeader`    |
| `Select.I18NNoMatches`           | `Select.I18nNoMatches`           |

### Typed contracts

String and loosely typed parameters now use wrapper enums or models where iX defines a stable shape. Common replacements include `ColumnSize`, `LayoutGridGap`, `ButtonVariant`, `RadioGroupDirection`, `CheckboxGroupDirection`, `InputType`, `TextAreaResizeBehavior`, `ToastType`, and `TimeReference`.

Callbacks that previously supplied strings, `dynamic`, or raw JSON now use the component's typed event model. Asynchronous handlers should return `Task` rather than use `async void`.

### Boolean attributes

Boolean iX attributes now follow presence semantics: `false` omits the attribute and `true` renders as `"true"`. Code that relied on a rendered `attribute="false"` value must not do so; iX now receives the correct `false` state.

## Navigation and layout

### Application and Menu

| 0.5.5                                 | 0.6.0                                                                          |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| `Application.ThemeSystemAppearance`   | `Application.ColorSchema`, default `ColorSchema.System`                        |
| `Menu.EnableMapExpand`, `I18NMore`    | Removed                                                                        |
| `MenuAbout.Show`, `MenuSettings.Show` | Removed; use `Menu.ToggleAboutAsync(bool)` or `Menu.ToggleSettingsAsync(bool)` |
| `ActiveTabLabel` values               | `ActiveTabKey` values                                                          |
| `MenuAboutNews.Expanded`              | Removed; use current tab/content behavior                                      |
| `ToggleAbout`, `ToggleSettings`       | `ToggleAboutAsync`, `ToggleSettingsAsync`                                      |

`SuppressLegacyTabs` only controls legacy tab rendering; it does not open or close a panel. Menu navigation now uses `Bottom`, `Href`, `Target`, and `Rel`. Menu, About, and Settings items use required `Id` and `TabKey` values and typed events. `ClosedEvent` uses `MenuCloseEvent`, `ActiveAboutTabKey` controls About navigation, and `AppSwitchConfig` follows the current ApplicationHeader contract.

### Tabs

Tabs now select by a stable string key instead of an integer index:

```razor
<Tabs ActiveTabKey="overview" TabChangeEvent="OnTabChanged">
    <TabItem TabKey="overview" Label="Overview">...</TabItem>
</Tabs>
```

| 0.5.5                      | 0.6.0                     |
| -------------------------- | ------------------------- |
| `Tabs.Selected`            | `Tabs.ActiveTabKey`       |
| `Tabs.SelectedChangeEvent` | `Tabs.TabChangeEvent`     |
| `TabItem.TabTitle`         | `TabItem.Label`           |
| No stable tab identifier   | Required `TabItem.TabKey` |

`TabItem.TabTitle` and the old Tabs chevron-label parameters were removed. `TabItem` retains the shared `Class`, `Style`, and `UserAttributes` parameters. Use `Closable`, `AriaLabelCloseButton`, `TabClickEvent`, and `TabCloseEvent` for the current interaction contract.

### Breadcrumb, layout, Pane, and Tree

| Area                    | Migration                                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Breadcrumb callbacks    | Use `BreadcrumbClick` and `BreadcrumbNextClick`.                                                                               |
| `Breadcrumb.NextItems`  | Change `string[]` to `BreadcrumbClick[]`.                                                                                      |
| `BreadcrumbItem`        | Set required `BreadcrumbKey`; remove `AriaLabelButton`. The previous-items label defaults to `Show previous breadcrumb items`. |
| Layout columns          | Change `Col.Size`, `SizeSm`, `SizeMd`, and `SizeLg` to `ColumnSize`.                                                           |
| `LayoutGrid.Gap`        | Change to `LayoutGridGap`; the default is `_24`.                                                                               |
| `Pane`                  | `CloseOnClickOutside` now defaults to `false`; borderless and expanded events use boolean payloads.                            |
| Tree model              | Use `Tree.Model`, `Tree.Context`, and `TreeItem`; `Root` defaults to `"root"`.                                                 |
| Tree expansion          | Use `ToggleOnItemClick`; rename `IsExpaned` to `IsExpanded`.                                                                   |
| Tree events and refresh | `NodeClicked` supplies a node ID; use `RefreshTree` and `MarkItemsAsDirty`.                                                    |

## Forms, selection, and date/time

### Inputs and validation

| API                              | 0.5.5                  | 0.6.0                                |
| -------------------------------- | ---------------------- | ------------------------------------ |
| `Input.Type`                     | `string`               | `InputType`                          |
| Input change callback            | `ChangeEvent`          | `IxChangeEvent`                      |
| Input validity callback          | Raw `JsonElement`      | `ValidityState`                      |
| `NumberInput.Value` and callback | Required numeric value | Current numeric/empty-value contract |
| `NumberInput.CssClass`           | Available              | Removed                              |
| `TextArea.CssClass`              | Available              | Removed                              |
| `TextArea.ResizeBehavior`        | `string`               | `TextAreaResizeBehavior`             |
| NumberInput/TextArea validity    | Raw payload            | `ValidityState`                      |

Use current `SuppressSubmitOnEnter`, alignment, focus, change, and validity APIs.

### CategoryFilter, Select, Upload, and KeyValue

- `CategoryFilter.InputChangedEvent` now uses `InputState`; `FilterClearedEvent` uses `FilterClearedEventArgs`; `StaticOperator` uses `LogicalFilterOperator`; category and filter models use the current `System.Text.Json` contract. `Icon` no longer forces the previous `search` default.
- `Select.Value` and `ValueChangeEvent` support the current single/multiple value contract. Rename `BlurEvent` to the parameterless `IxBlurEvent`, remove `AriaLabelChevronDownIconButton`, and use the current `I18n...` parameters. `I18nSelectListHeader` defaults to `Select an option`.
- `Upload` localization values are now optional; omit them to preserve iX defaults. `FileChangedEvent` remains `EventCallback<List<IXFile>>`; the `JsonElement[]` handler is an internal JavaScript boundary. Use `DirectoryUpload`, `UploadFileState`, and `SetFilesToUploadAsync` for the current API.
- `KeyValue.ChildContent` becomes `CustomValue` in the `custom-value` slot. `Label` is required, and `LabelPosition` uses `KeyValueLabelPosition`.

### Date and time

| Component                 | Migration                                                                                                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `DateDropdown`            | Remove `CustomRangeDisabled`, `I18NCustomItem`, `Ghost`, `Outline`, `Range`, and `DateRangeIdChanged`; use `ButtonVariant`, `SingleSelection`, `ShowWeekNumbers`, and the current `From`/`To` range contract. |
| DateDropdown localization | Rename `I18NDone` and `I18NNoRange` to `I18nDone` and `I18nNoRange`.                                                                                                                                          |
| `DateInput`               | Use `DateInputValidityState` and the current value, required, tooltip, and change contracts.                                                                                                                  |
| `DatePicker`              | The format default is `yyyy/LL/dd`; use the current range, week-number, accessibility, and navigation APIs.                                                                                                   |
| `DateTimePicker`          | Use `TimeReference` and `DateTimeDateChangeEvent`; `ShowTimeReference` is boolean. Use current range, time constraint, locale, and week-number APIs.                                                          |
| `TimeInput`               | Use `TimeInputValidityState`, typed alignment, `MinTime`, `MaxTime`, and `HideHeader`.                                                                                                                        |
| `TimePicker`              | Change `Corners` to `TimePickerCorners`; `MillisecondInterval` defaults to `100`; use the current-time API.                                                                                                   |

## Buttons, dropdowns, and overlays

### Button family and search

| Component          | Migration                                                                                                                                                |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Button`           | Remove `DataToggle`, `AriaLabelButton`, `Selected`, and `DataTooltip`. Replace `ButtonVariant.danger` with a supported variant such as `danger_primary`. |
| `IconButton`       | Remove `DataTooltip`, `A11yLabel`, and `Selected`; `Variant` defaults to `subtle_primary`.                                                               |
| `SplitButton`      | Remove `Ghost`, `Outline`, and `Placement`; use `DisableButton` and `DisableDropdownButton`. `ButtonClickedEvent` supplies `MouseEventArgs`.             |
| `DropdownItem`     | Replace `Value` and `OnClickEvent` with the current icon, state, role, content, and end-content APIs.                                                    |
| `ExpandingSearch`  | Remove `Ghost` and `Outline`; `Variant` uses `ButtonVariant` and now defaults to `tertiary`.                                                             |
| `IconToggleButton` | Use `IconButtonSize` and `ButtonVariant`; defaults are `_24` and `subtle_primary`. Remove `AriaLabelIconButton` and `ChildContent`.                      |
| `ToggleButton`     | `Variant` uses `ToggleButtonVariant` and now defaults to `subtle_primary`; remove the old icon-label parameter.                                          |

`Dropdown.Anchor`, `Trigger`, and `CloseBehavior` and `DropdownButton.CloseBehavior` now use the current object-backed contract. Use current focus, checked-item, label-content, and show-event APIs.

### Modal

Use `ModalService`, `ModalHost`, `ModalConfig`, and `ModalInstance<TReason>` for dialogs. Use `LoadingService` with `ModalLoadingOptions` and `ModalLoadingContext` for loading dialogs.

The old component parameters, `ShowAsync`/`HideAsync`/`ToggleAsync` methods, and `DismissedEvent`/`ShownEvent` callbacks are removed. Key replacements are:

| 0.5.5                  | 0.6.0                                                                           |
| ---------------------- | ------------------------------------------------------------------------------- |
| `Animation`            | `ModalConfig.Animation`                                                          |
| `BackdropClickClose`   | `ModalConfig.CloseOnBackdropClick`                                              |
| `AriaLabelledBy`       | `ModalConfig.AriaLabelledby`                                                    |
| `AriaDescribedBy`      | `ModalConfig.AriaDescribedby`                                                   |
| String `BeforeDismiss` | Typed `ModalConfig.BeforeDismiss`                                               |
| `DismissedEvent`       | Await `ModalInstance<TReason>.Closed` or `.Dismissed`, according to the outcome |
| `ShownEvent`           | No direct callback replacement                                                  |

Open dialogs through `ModalService` and control them through `ModalInstance<TReason>`. `ModalConfig` also provides `Backdrop`, `Centered`, `IsNonBlocking`, `Size`, `Content`, and typed `BeforeDismiss`; the old `CloseOnEscape`, `Container`, and `Keyboard` settings are not retained. `ModalHeader`, `ModalContent`, and `ModalFooter` no longer expose `Id`.

### Toast

The old imperative `Toast`/`ToastConfig` flow becomes declarative `Toast` or container-based `ToastContainer` usage. `ShowToast` returns `ToastResult`, which exposes state plus pause, resume, and close operations. Declarative `Toast` requires `Id`.

| 0.5.5                          | 0.6.0                                     |
| ------------------------------ | ----------------------------------------- |
| String `ToastConfig.Type`      | `ToastType`                               |
| `ToastConfig.PreventAutoClose` | `ToastConfig.AutoClose`; invert the value |
| `ToastConfig.MessageHtml`      | Use component content                     |
| `ToastConfig.Position`         | Set position on `ToastContainer`          |

`ToastConfig.AutoCloseDelay` and `ToastConfig.HideIcon` remain supported.

## Content and data display

### Cards and compact components

| Component            | Migration                                                                                                                                                                                 |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ActionCard.Variant` | Change from `PushCardVariant` to `ActionCardVariant`.                                                                                                                                     |
| `Card`               | Remove `AriaLabelCard` and `AriaLabelIcon`; use the current selected-state contract.                                                                                                      |
| `PushCard`           | `Expanded` now defaults to `false`; `PushCardVariant.primary` is available.                                                                                                               |
| `Blind`              | Remove `insight` and `notification`; `filled` is the default variant.                                                                                                                     |
| `CardList`           | `ShowAllClickEvent` and `ShowMoreCardClickEvent` receive `CardListClickEventArgs`; update parameterless handlers. Blazor callbacks cannot synchronously cancel the native default action. |
| `Chip`               | The close-button label now defaults to `Close chip`; `TooltipText` accepts the current string/boolean contract.                                                                           |

### Lists, controls, and workflow

| Component                   | Migration                                                                                                   |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `EventList`/`EventListItem` | `ItemHeight` accepts the current numeric/string contract; `Opacity` is removed; boolean defaults follow iX. |
| `Slider`                    | Remove `Error`; use validation, helper, `LabelStart`, and `LabelEnd`. `Step` defaults to `1`.               |
| `RadioGroup`                | Remove `CssClass`; `Direction` uses `RadioGroupDirection`; use current helper, value, and change contracts. |
| `CheckboxGroup`             | `Direction` uses `CheckboxGroupDirection`; Checkbox validation-state support is removed.                    |
| `WorkflowSteps`             | Remove `Linear`; use the current workflow layout.                                                           |

## AG Grid

The preview AG Grid wrapper is replaced by generic `AGGrid<TData>` support for AG Grid Community 35.2.0.

| 0.5.5                   | 0.6.0                               |
| ----------------------- | ----------------------------------- |
| `ColumnDefs`            | `AgGridColumnDefinition`            |
| `GridOptions`           | `AgGridOptions`                     |
| `OnCellClicked`         | Typed `CellClicked` callback        |
| Untyped operations      | `AgGridApi<TData>` and typed events |
| Custom infinite loading | `IAgGridInfiniteDataSource<TData>`  |

Use JSON and JavaScript extension points for feature-specific structures without a stable C# representation. AG Grid Enterprise modules are not included.
